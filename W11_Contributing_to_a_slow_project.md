# Contributing to 'slow' open source projects

So, you discovered that cool project, and found out that it is open source and public on Github!
You already know the project's programming language, and you know a little about the technology behind the project.
Why not contribute to it!

Not so fast... you are in front of a 'slow' project..

## What is a slow project?
Here, there is no notion about the speed of performance of the project itself.
It's the idea that once an open source project reaches a certain size, and / or has to rely on critical algorithms, then making it grow becomes a lot harder.
Even fixing an issue in an existing functionallity might get complicated.

In such projects, you can't just propose a new feature because you think it would be cool, and start working on it right away.
There are probably even rules on how you would contribute to that project, and not respecting them might get your contributions ignored, no matter how valid.
